CNC Chip Conveyor Timer

Operator's guide · one illuminated button, five programs · board PCB1 rev 1

What it does. The timer presses the conveyor's START and STOP buttons for you, in a loop: run for a while, stop for a while, repeat. While the conveyor stands still the coolant drains off the swarf back into the machine, so the chips reach the bin drier and the coolant stays where it belongs. When the timer is switched off, the START and STOP buttons on the panel work exactly as before.

Controls — one button

A command is a series of quick clicks. Click, click, click… then stop. The command is accepted 0.7 s after the last click (a beep confirms it).

Choosing a program starts the conveyor cycle at once and is remembered after power-off. The timer always powers up switched OFF.

Each START and STOP press lasts 0.5 s. Longer rest = drier chips, slower removal. Start with program 2 or 3 and adjust.

Automatic switch-off. After 4 hours of continuous running the timer switches itself off and sounds a 15 s signal. One click starts it again.

Good to know

· The two relays can never press START and STOP at the same time; every start begins with both released.

· Clicks during the power-on beep are ignored — wait for the lamp to go dark, then click.

· Too many clicks? Anything over six counts as six (program 5).

· A green LED inside the box shows the state for the technician: lit at power-on, one flash every 3 s when OFF, a different rhythm in each phase when running.

Before opening the box switch the machine off. The relays carry the machine's START/STOP circuit; the board runs on 24 V.
